# IBM Cognos Analytics – Reporting Project (SuperStore Dataset)

This project contains a complete set of reports created in **IBM Cognos Analytics Cloud** using the SuperStore Orders dataset.  
It includes list reports, crosstab reports, conditional formatting, summary calculations, and multiple levels of filtering.

---

## 📌 Project Overview

As part of my learning in **Business Analytics**, I explored how enterprise BI tools handle:

- Report creation  
- Data aggregation  
- Conditional formatting  
- Nested crosstab structures  
- Detail and summary filters  
- Query and layout design  
- Business-ready reporting  

---

## 🧩 Features Implemented

### **✔ Part A – List Reports**
- Gross Profit Report (calculated field)  
- Revenue Summary Report with totals  
- Planned vs Actual Revenue Report  
- Aggregations: SUM, AVERAGE, MIN, MAX  

### **✔ Part B – Crosstab Reports**
- Country × Year Quantity Crosstab  
- Revenue Crosstab with color-based conditional formatting  
- Planned Revenue Crosstab with row and column totals  

### **✔ Part C – Filters & Multi-Level Crosstab**
- Detail Filters (Year, Country)  
- Summary Filters (Total Revenue)  
- Combined Filters (Country + Year)  
- Advanced Filters (IN, BETWEEN)  
- Region → Country nested crosstab with multiple measures
